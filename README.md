# Fake News Detection

## Project Overview
Fake News Detection is a machine learning-based web application designed to classify news text as Real News or Fake News using Natural Language Processing (NLP).

## Features
- Upload a news dataset in CSV format
- Preview dataset records
- Preprocess text and labels
- Split data into training and testing sets
- Train a Logistic Regression model using TF-IDF features
- Display prediction results and model evaluation metrics

## Technologies Used
- Python
- Flask
- Pandas
- Scikit-learn
- TF-IDF Vectorization
- HTML and CSS

## How to Run
1. Install Python.
2. Install the required packages using `pip install -r requirements.txt`.
3. Run the application using `python app.py`.
4. Open the local URL displayed in the terminal.

## Project Purpose
To explore how machine learning and text processing can help classify news content.

## Note
Predictions are model-based classifications and should not be treated as definitive verification of news authenticity.
